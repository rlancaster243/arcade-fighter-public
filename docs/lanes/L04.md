# Lane 04 — Match directing

Implements `MatchDirector` (`MatchDirecting`) in `FightCore/Sources/FightCore/Match/`, replacing the scaffold stub via `typealias MatchDirectingStub = MatchDirector` (frozen `Sim/` still defaults to the alias).

## Responsibilities

- Round flow: first to 2, max 5 rounds, KO and time-over resolution, draws award no round.
- Timer: 5940 ticks per round; `displaySeconds` uses `ceil(remaining/60)`; round timer pauses during hitstop.
- Meter: cap 1000; hit / half on block / chip; defender 25% of damage taken; super spends 1000 on startup (`attackStartup`, `stateTick == 0`, `isSuper` metadata).
- Hitstop from move metadata; super moves enforce at least 10 ticks (super freeze).

## Move metadata

`MatchDirector` accepts `[String: MatchMoveMetadata]` for `meterGain`, `hitstop`, and `isSuper`, populated outside the per-tick path (e.g. from fighter defs at sim init). Empty map yields hitstop/meter gain only where derivable (defender % from `damage`).
