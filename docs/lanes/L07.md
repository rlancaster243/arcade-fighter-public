# Lane L7 — App shell & menus (`T-APPLOGIC-MENU`)

## AppLogic (`FightCore/Sources/AppLogic/Menus/`)

- `MenuShellState` + `MenuReducer` — platform-free state machine for title, main menu, arcade ladder, versus setup, character select, in-match pause/rematch, result screen, and settings.
- `FighterRoster` — roster ids until L9 content lands (`greybox` only).
- `DisplayLayout` — 384×216 integer scale + letterbox math; pairs with `DisplayPreferences.wantsFullscreen` / `windowIntegerScale`.
- `MatchBootstrap` — builds a `GameSnapshot` from `MatchSetup`.

## App (`App/Shell/`)

- `ShellRootView` — SwiftUI router over menu screens and greybox match preview.
- `WindowPresentation` — applies fullscreen vs windowed minimum size from settings.
- `MenuKeyboardBridge` — macOS keyCode bridge for menu commands (does not drive fight inputs; L8).
