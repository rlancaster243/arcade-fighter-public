# Lane L5 — AI and FightSim harness

## Delivered

- `DifficultyProfile` for easy / normal / hard with match-seeded reaction delay, input accuracy, block, special, and super rates.
- `CPUAIController` implementing `AIController` (stateless epoch decisions, no Foundation on the tick path).
- `AIMatchDriver` and `FightSimBatchReport` for CPU-vs-CPU batches.
- `FightSim` CLI: `--seed`, `--batch`, `--ticks`, `--p1`, `--p2`, `--json-out` (JSON on stdout by default).
