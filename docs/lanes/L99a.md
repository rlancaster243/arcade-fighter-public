# Lane 99a — Playable local match (macOS app)

## Integration

- `App/AppMain.swift` hosts `ShellRootView` (menus + match).
- `LocalMatchSession` loads fighter JSON, runs `Simulation` at 60 Hz, and publishes `GameSnapshot` to `MenuShellModel`.
- Arcade CPU drives P2 via `CPUAIController`; versus uses keyboard/gamepad adapters for both players.
- `MatchPreviewView` keeps one `GreyboxScene` and updates `snapshot` each tick.
- `SFXEventPlayer` plays `Content/Audio` clips when `GameEvent`s arrive.

## Play flow

Title → Main menu → Versus or Arcade → Character select → Fight (P/Esc pause → resume; result screen → rematch prompt).
