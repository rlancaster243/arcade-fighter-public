# Lane L8 — Input adapters

## AppLogic (`FightCore/Sources/AppLogic/InputMap/`)

- `MacVirtualKeyCode` — HIToolbox `kVK_*` table shared with adapters
- Default P1 WASD + F/G/H/J; P2 arrows + numpad or alternate I/O/K/L
- `InputRemapSettings` remap model (JSON, persisted in app `UserDefaults`)
- `KeyboardInputSampler` / `GamepadInputSampler` → `InputFrame`
- `InputMapSession` — dual-keyboard routing + optional gamepad override for P1

## App (`App/Input/`)

- `KeyboardInputAdapter` — `NSEvent` local monitor, ignores `isARepeat`
- `GameControllerInputAdapter` — `GCExtendedGamepad`, deadzone **0.5**, 8-way
- `KeyTestScreen` — live key-code log and P2 layout picker
- `InputRemapStore` — `UserDefaults` persistence
