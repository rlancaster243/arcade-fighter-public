# Lane L2 — Fighter stepping

## `FighterStepper`

Replaces `FighterSteppingStub` with a frame-data executor and per-fighter state machine.

### Motion / input convention (L1)

- **Neutral move:** set `activeMoveID` to the move id for one tick; stepping clears it when the attack starts.
- **Jump:** set `activeMoveID` to `FighterConstants.builtinJumpCommand` (`__jump__`).
- **Recovery cancel:** while in `attackRecovery`, set `activeMoveID` to the cancel target move id (must differ from the executing move) during the last `FighterConstants.normalRecoveryCancelFrames` recovery frames.
- **Throw tech:** defender sets `activeMoveID` to the same throw move id on the active frame of the opponent’s throw.

### Mechanics in this lane

- Attack phases driven by `startup` / `active` / `recovery` from `MoveDef`.
- Walk velocity from `walkForward` / `walkBack`; jump startup → airborne → landing.
- Projectile spawn on first active frame of `sp_qcf` (and moves whose id ends with `_shot`).
- Throw connect on throw `attackActive` within `FighterConstants.throwRangeRaw`.
- Invulnerability when the current move frame has empty or zero-area hurt boxes (`MovePhaseMath.isInvulnerableFrame`).
- Single armor hit on `sp_dp` (`consumeArmorHit` for collision).
