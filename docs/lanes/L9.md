# Lane L9 — Kestrel, Bruno, Stage 1

Shippable content for the first playable roster slice.

## Fighters

| Id | Display name | Archetype | Notes |
|----|--------------|-----------|-------|
| `kestrel` | Kestrel Vane | rushdown | Faster walk; ice-themed specials and **Blizzard Waltz** super |
| `bruno` | Bruno Okafor | brawler | Higher health; heavy normals and **Forge Break** super |

Each fighter lives in `Content/Fighters/<id>/<id>.contentbundle/` with a bundle `Info.plist`. The app target copies `Content/` via a Run Script phase (not Xcode’s synchronized-root flattening) so duplicate `fighter.json` / `sheet.json` basenames never collide in `Resources/`. Bundles follow `docs/fighter-schema.md` (`<id>.png` plus the `<id>_alt.png` P2 costume, `sheet.json`, `fighter.json`). The sheets are RGBA 224×224-cell anime cel art generated by `scripts/art/gen_fighters.py` from the designs in `scripts/art/fighter_designs.py`; see "Fighter art" in the schema doc.

## Stage

`Content/Stages/stage1/` — **Glacier Forge Quarry** (`stage.json` + three parallax layers `glacier_sky.png`, `glacier_forge.png`, `glacier_quarry.png`; 1536×432 truecolour at `texelScale` 2, generated by `scripts/art/gen_stages.py`). Bounds in JSON are logical fight space for future app wiring.
