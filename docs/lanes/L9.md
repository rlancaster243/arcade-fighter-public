# Lane L9 — Kestrel, Bruno, Stage 1

Shippable content for the first playable roster slice.

## Fighters

| Id | Display name | Archetype | Notes |
|----|--------------|-----------|-------|
| `kestrel` | Kestrel Vane | rushdown | Faster walk; ice-themed specials and **Blizzard Waltz** super |
| `bruno` | Bruno Okafor | brawler | Higher health; heavy normals and **Forge Break** super |

Each fighter lives in `Content/Fighters/<id>/<id>.contentbundle/` with a bundle `Info.plist`. The app target copies `Content/` via a Run Script phase (not Xcode’s synchronized-root flattening) so duplicate `fighter.json` / `sheet.json` basenames never collide in `Resources/`. Bundles follow `docs/fighter-schema.md` (indexed PNG, `sheet.json`, `fighter.json`).

## Stage

`Content/Stages/stage1/` — **Glacier Forge Quarry** (`stage.json` + `background.png`, 384×216 indexed). Bounds in JSON are logical fight space for future app wiring.

## Tests

`FightCore/Tests/ContentTests/L9/L9ContentTests.swift` — loader validation for both fighters and stage bundle presence.
